A visual language for self-reference

Brian Mills · October 2026

Sentences like “this sentence is false” are hard to think about in symbols. This project draws them so that two things hold at once: every drawing reads back into exactly one formula, and paradox has a shape you can see. Drawn on a true layer and a false layer, the liar is a single loop that crosses itself (a figure 8), while “this sentence is true” is two separate loops.
