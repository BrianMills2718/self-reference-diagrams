# Instructions for agents working in this repository

Start by reading `HANDOFF.md`: purpose, how Brian likes to work, what exists, decisions in force, and next steps.

Then, before any change to the notation, read `docs/foundation.md` (the closed list of marks, section 10) and `docs/specification.md`.

Rules that matter most:
- Show Brian a mock before building or deploying.
- No new mark without amending foundation section 10 first.
- Cite a standard source for every idea; do not invent formalisms.
- Run `tests/run-all.sh` before claiming anything works, and after any change to `src/`.
