Round-trip test: every drawing reads back exactly, in both layouts

This page checks the formal specification by program. It generates random sentences, draws each one following the drawing rules, then reads the drawing back from the positions of its shapes alone: what is inside which outline, where each arrow ends, where each heavy line runs. A ✓ means the read-back is exactly the original formula.

Value layers on random loops: the figure 8

Each random loop of sentences, drawn on a true layer (top) and a false layer (bottom). A value crosses layers at each “not”. One closed curve through both copies (a figure 8) should mean no consistent value; two separate curves should mean either value holds. Each card checks that against a brute-force search for consistent values.

Deliberately broken drawings are rejected

One drawing broken four ways. Each break violates one drawing rule, and the read-back refuses it and names the rule.

The unfolding: evaluation as a derivation

Each step applies one rule (unfold, look up, double cut) and is itself a drawing that reads back exactly. Evaluation halts when the sentence is reduced to true or false; if a drawing comes back that was seen before, it will cycle forever.
