Self-reference diagrams v0.2: see it work

Each example shows the standard symbolic form, the drawing, and where each assignment of true and false leads. The page reads every drawing back into logic using only its geometry (what sits inside which box, where each arrow lands, which areas a heavy line reaches) and checks the result against the symbolic form. The verdicts are then computed from that read-back, not from the symbolic form.

Each sentence carries its verdict, computed from what the drawing says. Press Show why under any example to open the reasoning: where each assignment of true and false leads. Click a state there to see it on the drawing. Each sentence box is outlined green for true or orange for false, and dashed if its content disagrees, so the next step will change it. Each claim is filled green if it holds in that state and orange if not, and a short explanation says why each sentence stays or changes. Step follows the arrow.
