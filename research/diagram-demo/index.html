Reasoning through constraints

A review atlas: ordinary inference, self-reference, scoped investigations, and exact changes of view.

Status: proposed drawings using established factor-graph and Peirce notation. The mathematical checks below do not establish human intelligibility. These are static review pictures; no live tutorial or notation has been adopted.

Reading order: start with 01. T and F mean true and false; 0 and 1 abbreviate F and T. Circles name value variables. Squares name relations. Lines indicate which variables a relation constrains. Panel borders only group pictures.

Ordinary meaning: Snow is a constant symbol; it names entity:snow in the declared two-entity domain. Falling is a unary predicate (a property of one entity). p records whether that entity belongs to Falling’s interpretation. The name, entity, predicate, sentence, and value have distinct records. q similarly records Blowing(Wind). “All worlds” below means all combinations of the listed observations, with other ordinary facts ignored.

Read the sheet as an assertion; read the network as a set of simultaneous constraints. The = square links a sentence’s candidate value to its body value.

Tr(S) uses the registry entry S. Its value is the candidate s. The teller’s equality permits both choices; the liar’s two constraints permit neither.

Every case keeps the same source identifiers. Only the assigned values differ. The four panels exhaust p and s; unmentioned world facts may vary freely.

An unassigned domain {F,T} is a search status, not a third truth value. The p=T branch demonstrates that local propagation can stop before detecting a global conflict.

The displayed ≠ relation summarizes an exact joint projection. Its two tuples carry source witness identifiers in the evidence. The collapsed liar remains part of the global query.

The lower construction is the signed double cover (two value copies linked according to reference polarity). It is a different view from factor incidence; shared shape is not assumed.

Evidence and remaining questions

The independent checker compared direct formula evaluation with exhaustive assignments to compiled constraints: 10 fixtures, 1,348 compiled assignments. It replayed 186 local traces and checked 112 finite views. All 510 signed cycles of lengths 1–8 were checked against the parity criterion.
